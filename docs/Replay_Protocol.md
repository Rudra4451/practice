# TyProX 7-Layer Replay Protocol v2

Replays store event streams instead of snapshots.

## 7 Timeline Layers
1. **Cursor Layer**: Active target character index pointer.
2. **Input Layer**: Current typed string state.
3. **Error Layer**: Character mis-strike overlay.
4. **WPM Layer**: Instantaneous WPM curve calculation.
5. **Rhythm Layer**: Keystroke interval stability bar.
6. **Heatmap Layer**: Per-key latency heatmap overlay.
7. **DNA Marker Layer**: Milestone keyframe markers.
